Day thirty-one. Ek sawaal, aur imaandaari se jawaab dena.
Naya phone liya tha, toh uski ringtone, aapne kabhi badli? Zyaadatar log, jo pehle se set hai, wahi chalne dete hain.
Ek mashhoor study mein dekha gaya, jin deshon mein organ donation ke liye khud haan karna padta hai, wahan bahut kam log donor bante hain. Aur jahan haan pehle se chuna hota hai, wahan lagbhag sab.

Par iska galat istemaal bhi hota hai. Pehle se tick kiya hua insurance, ya donation, jise user ne maanga hi nahi. Ye default nahi, chaalaaki hai.
Toh default wahi rakho, jo zyaadatar users sach mein chahte hain. Aur badalne ka raasta, hamesha aasaan rakho.
Aapke phone mein aisi kaun si setting hai, jo aaj tak nahi badli? Comment mein batao. Kal milte hain, Endowment Effect ke saath.
